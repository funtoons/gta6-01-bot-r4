Solmarina — a pseudo-3D open-world crime game in an original sun-soaked coastal city, built for make.fun's "Make GTA 6" bounty ($1,666 in USDC). Chase-cam driving down golden-hour avenues, on-foot streets full of pedestrians, a 1–5 star wanted level with SCPD pursuit, roadblocks and a helicopter spotlight, 6 story missions (Mama Zola, Rio, Vex and Marlo's crew), combat, taxi fares, vigilante takedowns, package hunting, checkpoint races, respray shops, synth radio, save/Continue and a full career-stats screen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. WASD drive / walk, E enter & steal cars, F shoot, Q weapon, R radio, P pause, M map, C stats, G save.
